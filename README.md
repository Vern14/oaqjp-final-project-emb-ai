## Emotion Detector

This repository contains the capstone project for the "Developing AI Applications with Python and Flask" module, which is part of the IBM Full Stack Software Developer Certificate curriculum. The goal of this application is to construct a Flask-based web system driven by AI that analyzes user-submitted text inputs and generates an evaluation detailing the specific emotions expressed within that text.
